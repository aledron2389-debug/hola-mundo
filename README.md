# Hola Mundo

Proyecto sencillo para practicar Git y GitHub.

## Ejecutar

Con Python 3 instalado, ejecuta:

```bash
python hola_mundo.py
```

El programa muestra:

```text
¡Hola, mundo!
```

## Revisión del docente

La idea es abrir una solicitud de cambios (pull request) desde la rama `hola-mundo` hacia `main` para que el docente pueda revisar el proyecto.
